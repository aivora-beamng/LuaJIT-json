The JSON module is an extension of the String Buffer Library, adding functionality to encode and decode between JSON format and Lua objects. The JSON encoder generates minified JSON (without whitespace). The JSON parser is non-validating and also parses JSON with comments and the SJSON format. The JSON module is compiled-in by default, but you can disable it by setting -DLUAJIT_DISABLE_JSON at compilation time.

Serialization Functions and Methods

str = buffer.jsonencode(obj)
buf = buf:jsonencode(obj)

Serializes (encodes) the Lua object obj to JSON. The stand-alone function returns a string str. The buffer method appends the JSON encoding to the buffer.

obj can be any of the supported Lua types — it doesn't need to be a Lua table.

This function may throw an error when attempting to serialize circular references or deeply nested tables.

Attempting to deserialize an FFI or another unexpected type will result in the `null` value.

obj = buffer.jsondecode(str)
obj = buf:jsondecode()

The stand-alone function deserializes (decodes) the JSON string str, the buffer method deserializes one JSON object from the buffer. Both return a Lua object obj.

The returned object may be any of the supported Lua types — even nil.

This function may throw an error when fed with malformed or incomplete encoded data. The stand-alone function throws when there's left-over data after decoding a single top-level object. The buffer method leaves any left-over data in the buffer.
